<h1 align="center">🦎 GECKO 🦎</h1>
<h3 align="center">General Engine for Custom Keyboard Optimization</h3>

**GECKO** is a terminal/web application designed to optimize custom keyboards and layouts. The goal is to generalize a keyboard and layout to a set of general parameters and use a suite of data analysis tools to iterate toward an optimal outcome.

- Find an optimal keyboard layout, given any physical keyboard
- Optimize physical keyboard designs
- Extremely generalizable cost (analysis) function
  - In depth analysis of any keyboard layout
