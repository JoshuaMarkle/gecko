# Journal paper template

Open `journal.html` directly in a browser. `index.html` forwards to it.
No build, server, JavaScript, or network required.

The single retained template has a centered title, Joshua Markle / University of
Virginia author details, a full-width abstract with generous surrounding space, and
a continuous two-column body that becomes one column on mobile. The title has no
corner labels or divider above the abstract.

Edit `journal.html` and `paper.css`. Browser printing uses A4 styles. On screen, the
white sheet sits on a neutral gray background with generous margins and thin edges.
Its height grows with the article; this is a flowing web paper, not a fixed-page
journal submission.

Colors and font stacks come from `web/src/styles.css` and `context/design.md`.
Reading sizes are larger than application controls. Inter is used if installed,
otherwise the site's system fallback. Blue highlights selected plot data.

## Figures

The SVGs in `assets/` are standalone, scalable figures generated by Matplotlib.
All data are synthetic, not GECKO measurements. PCA is actually computed with SVD
from a seeded standardized matrix; convergence and metric values are illustrative.

Regenerate from the repository root (requires Python, NumPy, Matplotlib):

```sh
MPLCONFIGDIR=/tmp/gecko-mpl python docs/papers/templates/generate_figures.py
```

Replace sample data, captions, author metadata, and prose before publication.

## PDF / LaTeX export

`journal.pdf` is the compiled four-page A4 paper. The HTML page offers PDF and LaTeX
download links. These links serve the last build; they do not compile in the browser.

Rebuild from the repository root:

```sh
./docs/papers/templates/build_pdf.sh
```

### Split: style vs content

- `gecko-paper.cls` holds all PDF styling: page, fonts (with the Latin Modern fallback),
  colours, sizes, headings, captions, footer, and the macros below.
- `journal.tex` (the specimen) and `skeleton.tex` (blank starter) hold content only.
- `build_pdf.sh [paper.tex]` builds any paper, in any folder, using this folder's `.cls`;
  it checks that every `\paperfigure{name}` (or `\paperwidefigure`) has `assets/name.pdf` beside the paper.

| Macro / environment | Use |
|---|---|
| `\paperfooter{left}{right}` `\paperpdfinfo{title}{author}{subject}` | footer, PDF metadata |
| `\papertitle \papersubtitle \paperauthor \paperaffil \papernotice` then `\makepapertitle` | title block |
| `paperabstract`, `paperbody` | full-width abstract; two-column body (put the bibliography inside) |
| `\paperfigure{name}{caption}`, `papertable{caption}` | figure from `assets/name.pdf`; captioned table |
| `\paperwidefigure{name}{caption}` | text-width figure; breaks and resumes the two columns |
| `papercode` | small monospaced verbatim block (short lines) |
| `\papercite{key}`, `\citetarget{key}`, `\paperbibstyle` | linked citations and bibliography style |

Standard LaTeX (`\section`, `\subsection`, `\textit`, `tabular*`, `booktabs`) works unchanged.
Edit `journal.html` and `journal.tex` together while the specimen exists; the HTML view is not
needed for new papers.

The PDF preserves the journal's centered title, full-width abstract, two columns,
blue figure accents, and author details. Typesetting and pagination are handled by
LaTeX rather than screenshotting the webpage. Noto Sans is used for the PDF (Inter
is not installed locally), with DejaVu Sans Mono for paths.

Requires XeTeX/XeLaTeX and the packages listed in the preamble, plus those two fonts.
The build runs twice with shell escape disabled and keeps intermediates in a temporary
directory. If `xelatex.fmt` is missing, it initializes a temporary format from the
installed `xelatex.ini` without altering system configuration. The source also handles
missing default Latin Modern OpenType fonts using Noto Sans. Failed compilation saves
`journal-build-error.log` for diagnosis; it does not overwrite the last successful PDF.

The figure generator writes both SVGs for HTML and vector PDFs sized for paper columns.
Regenerate figures before rebuilding when changing plot data. The checked-in figure PDFs
allow normal LaTeX builds without Python. The exported paper was rendered and visually
checked on all four pages; the successful build has no overfull-box or missing-glyph warnings.

PDF typography: 9pt body, 8pt captions/table text, 9pt section headings, 20pt title.
Section/subsection/abstract headings use a lightly strengthened Noto Sans Medium at a consistent 9pt (matching body text);
the title and caption labels retain Noto Sans Medium. Plot labels are
6.5–7pt at column size. These PDF settings are independent of the HTML reading sizes.

The expanded specimen includes related work, experimental setup, subsections, discussion,
limitations, reproducibility, a conclusion, declarations, an appendix, and five fictional
bibliography entries. Numbered in-text citations resolve through LaTeX’s built-in
bibliography (no BibTeX/Biber step); HTML citations link to the matching entries.
The bibliography is placeholder content for evaluating styling, not research evidence.

Heading spacing below is 3pt for sections and 2pt for subsections, with space above
unchanged. In-text PDF citations are 6.5pt blue links to bibliography entries, using
native xdvipdfmx annotations (avoids the local hyperref dependency on missing pzdr).
HTML uses matching linked citation styling and consistent 14px semibold section headings.

Heading weight is tuned to Noto Sans Medium with `FakeBold=1.5` in the PDF and
900 in HTML; heading sizes and spacing remain unchanged.
