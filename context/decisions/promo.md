# Promo decisions

- 2026-10-28 — The promo is a Remotion project in `promo/` with its own `package.json`, React Three Fiber via `@remotion/three` — frame-exact renders, and the 3D board shares the web viewer's pose convention.
- 2026-10-28 — 2D panels that move in 3D (tunnel, app lift-off) are DOM in CSS 3D (`ui/space.tsx`), not textures in WebGL — text stays sharp and the components are plain React.
- 2026-10-28 — Floor shadow is the key light's VSM shadow on a shadow catcher, not drei `ContactShadows` — its render target never drew under Remotion's stepped `advance()`.
- 2026-10-28 — `Scene3D` advances R3F again after mount (`Settle`), and `STLModel` holds the frame until its meshes are drawn — ThreeCanvas advances once per frame, before EffectComposer passes or async meshes exist.
- 2026-10-28 — Scene 4 swaps legends along the SA worker's current layout, not `best_chars` — the layout run has only 39 distinct best layouts in 504 snapshots, so the board would sit still.
- 2026-10-28 — Mono type is JetBrains Mono (OFL, bundled) — the product's `ui-monospace` stack cannot be bundled into a render.
- 2026-10-28 — `Hands3D` imports the product's `web/src/hand.ts` (placement, finger and thumb IK, typing plan) and runs it at 1 unit per mm; `three/HandMesh.ts` is a port of the Hand tab's `Rigged`, not an import — that file pulls in Vite `?url` assets and the web viewer's components. GLBs are copied to `public/hands/` by `npm run data`.
- 2026-10-28 — Scene 8's callouts show reach (mm), press angle (from the IK pose), the scorer's per-key `reach` and `wrist` costs, and pronation — not wrist deviation and extension: WASM `hand_costs` gives 0° for both at rest for the average hand on corne-42, so they would never move.
- 2026-10-28 — Stat leaders (`StatCallout`, `StatRing`) are copper PCB traces (`ui/trace.tsx`): pad on the measured point, octilinear runs with 45° turns, via at the label. Pinky–ring's ring now points at a right-hand ring-finger key so no two traces cross.
- 2026-10-28 — The nice!nano has a clear glass cover on four standoffs past the nano's ends; a transmission material plus a fixed two-band reflection texture on the top face, because the environment reflection alone barely shows at near-normal views.
- 2026-10-28 — The app-shell view shows the Optimize › Layout tab (`ui/LayoutPage.tsx`: settings, best layout, convergence, score vs QWERTY), not Home.
- 2026-10-29 — Storyboard v4: black/white/blue and no headlines (reverses v3's light mode and per-scene copy) — the user asked for a visual, demonstrative cut with little text in that palette.
- 2026-10-29 — Dark theme by inverting the token values, not the names (`C.ink` is white, `C.canvas` black) — every component re-themes without per-component edits.
- 2026-10-29 — The 3D floor is `meshLambertMaterial`: a standard material's 4 % specular lit the "black" floor to grey.
- 2026-10-29 — Hands are shot from the side: the GLB forearm ends in a cap that faces the typist, and shader or vertex-colour fades did not hide it.
- 2026-10-29 — Board2D draws Corne3D's 36 mm split (`SPLIT_U`) so the drawing sits exactly over the orthographic 3D top view at the hand-off.
- 2026-10-29 — Storyboard v5: back to light mode with the product's own token values (reverses v4's black stage and the inverted-token theme) — the user's review asked for light mode everywhere.
- 2026-10-29 — No switch LEDs or underglow (the per-key light pool and LED emissive are gone) — the user asked to remove the glow under the keys; bloom went with them.
- 2026-10-29 — The nice!nano's glass is a thin transparent coat, not a `transmission` material — transmission draws what is behind it from a low-resolution buffer, so the silkscreen stayed soft whatever the depth of field focused on.
- 2026-10-29 — The 2D board draws legends at the 3D caps' scale (`three/legend.ts` `LEGEND`, `LEGEND_MM`) — 2D icons were 2.3× the 3D ones and visibly jumped at the 3D → 2D hand-off.
- 2026-10-29 — The Optimize stats are a strip under the board with no leaders — leaders to each metric's most frequent bigram were tried and crossed the board; the stats describe the whole layout, so any one key they point at is arbitrary.
- 2026-10-29 — Tunnel charts are camera-facing billboards in mirrored pairs on the grid lines, with no cards, and nothing at the tunnel's end — the user found the wall panels asymmetric and off the grid; distant pairs fog out early so transparent charts don't stack along the axis.
- 2026-10-29 — The document page is set in Inter, not a serif — only bundled fonts render reproducibly, and a sans matches a modern word processor's default. The chart in that scene counts the page's own letters as they land (the chained lines), in corpus-frequency column order.
- 2026-10-29 — The low front hand shot is framed so the forearms leave the top of frame — the GLB forearm's cut faces the typist, so it shows from the front; the skeleton returns to the side view.
- 2026-10-29 — The video ends on the wordmark; no push back into the opening macro (no loop) — the user asked to end on the GECKO name.
- 2026-10-29 — Layout-search legends change in place (cross-fade) instead of travelling on arcs — the user found the moving letters looked bad.
- 2026-10-29 — The Language chart takes data ticks along its baseline and fades them in at its left edge; no blue hop onto each bar — the user asked for ticks flowing into the chart and the chart changing. The chained lines leave the page glyph by glyph, after the tilt, and the page slides right ahead of the line's end — with a fixed page, later lines' glyphs fly ever farther, overtake one another and read backwards.
- 2026-10-29 — The Physical camera is one orbit from the skin shot past the side (skeleton at 115°) and on round the board (343°) into the board view, with continuous angular speed (sin² bursts around a 0.3°/frame drift) — the user asked not to rotate back. Scene lengths for Language, Physical and App come from their own timing constants.
- 2026-10-29 — The STL shot shows the case only; the bottom plate is left out for now (user request).
- 2026-10-29 — The document's lines stay on the tilted page (no pop-off); only the chained lines leave it — the user asked for the text to stay on the page as it turns.
- 2026-10-29 — The page's slide is a Hann-windowed average (two lines wide) of its continuous ideal position, not a 25-frame box of a per-glyph step — the box left a 1–2 frame velocity spike at every line break (the jitter the user saw); the Hann halves sum to a constant, so the page glides at a steady speed.
- 2026-10-29 — The Physical skeleton types the whole opening sentence and keeps typing until a second after the orbit reaches the board view, then "Optimize for" switches; only the final board score turns blue, not the range bars (user request).
- 2026-10-29 — The Home flowchart's Derived column is one Scoring box, and Layout reads "SA" — the three-box column and "SA · BLS · GA" overflowed their boxes at panel size.
- 2026-10-29 — Keycaps are matte (roughness 0.92, no clearcoat or sheen) and the nano's glass is near-invisible (2 % opacity, faint reflection bands) — the user found the caps shiny and the glass too visible. The rise to the top view takes 1.8 s and the ortho blend 0.4 s (were 4.4 s and 0.8 s); the C on the end card is pressed half a second later.
- 2026-10-29 — The component sheet (`npm run components`, `src/sheet/`) is a Vite page, not Studio compositions: 2D components as still frames (Remotion `Thumbnail` at a settled frame, no playback; the user asked for no video), and a 3D viewer with drei `OrbitControls` in place of `CameraRig`, one model (one WebGL context) at a time. No React StrictMode: its double effects dispose `Hands3D`'s rigged meshes.
- 2026-10-29 — The Corne's plate, PCB and bottom are each one outline: the finger rows (and MCU column for PCB/bottom) united with each thumb key's rectangle (turned as the key is, so the bottom edge steps around the keys) and a convex filler from the keys' tops up to the finger rows; a strip under the middle column (to the pinky columns' bottom edge, y 3.42 u, out to the thumbs) carries the post under C; the thumb cluster sits 0.3 u higher (thumb centres y 3.9 / 4.0 / 4.0). — Separate overlapping thumb pieces showed seams and a gap between the second thumb and the big key.
- 2026-10-29 — The tunnel has no wall grids: the charts float on the white stage alone (user request).
- 2026-10-29 — The README banner is its own still composition (`banner`, `src/Banner.tsx`) that reuses the end card's `Keycaps` at a settled frame with the halo at 25 %, on a rounded white card with a soft shadow and a transparent margin — the user asked for the end frame as a banner with little glow.
