# research/

Background research behind GECKO's design. Read the file you need, not all of them.

| File | Read when |
|---|---|
| [existing-optimizers.md](existing-optimizers.md) | Porting or comparing against another tool, or choosing what to borrow |

| [parameters.md](parameters.md) | Designing config/schema: what describes a keyboard, what steers optimization |
| [hand-model-and-geometry.md](hand-model-and-geometry.md) | Working on 2D/3D physical geometry or the hand model |
| [data-sources.md](data-sources.md) | Building corpora or timing models |
| [design-draft-v0.md](design-draft-v0.md) | History only. The agreed design now lives in `context/` |

## Confidence notes

Research was done 2026-10-20. Some primary sites (carpalx at bcgsc.ca, the Aalto
136M keystrokes page) were unreachable from the research environment, so a few
details are from secondary sources or memory and are marked **(verify)**. Check
the primary source before hard-coding any number marked that way.
